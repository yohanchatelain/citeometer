🚀 How to Embed on Any Website

Add the following two lines anywhere on your personal website (Jekyll, Hugo, plain HTML, or GitHub Pages):

<!-- 1. Include CSS and JS in your <head> or before </body> --> <link rel="stylesheet" href="https://yourusername.github.io/paper-metrics-widget/src/paper-metrics.css"> <script src="https://yourusername.github.io/paper-metrics-widget/src/paper-metrics.js" defer></script>

Then place the Web Component or HTML tag in your publications list:

<!-- 2. Inline badge example --> <paper-metrics doi="10.1371/journal.pone.0295069" ads="2024PLoSO..1995069S" layout="badge"></paper-metrics> <!-- Or rich card view --> <paper-metrics doi="10.1371/journal.pone.0295069" layout="card"></paper-metrics>
