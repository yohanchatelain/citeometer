Install

Works on any static site

Jekyll, Hugo, Quarto, al-folio, plain HTML or GitHub Pages. No build step required.

1

Load the script

One tag in your <head>. The bundle injects its own styles.

HTML
<script src="https://cdn.jsdelivr.net/gh/yohanchatelain/citeometer@v1.0.0/dist/citeometer.min.js" defer></script>
2

Drop in a tag

Use any identifier you have: DOI, arXiv, ADS bibcode, Zenodo, bioRxiv or GitHub repo.

HTML
<cite-o-meter
  doi="10.1371/journal.pone.0295069"
  layout="badge"></cite-o-meter>
3

Match your theme

Every color and the font are CSS variables. Dark mode follows the visitor’s system.

CSS
:root {
  --pm-font: inherit;
  --pm-cites-text: #8c1515;
  --pm-radius: 6px;
}
